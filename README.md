# Center Mouse Shortcut GNOME Extension

## Features

Adds two configurable keyboard shortcuts:

| Shortcut                        | Default Key Binding |
| ------------------------------- | ------------------- |
| Center mouse on current window  | Super+Z             |
| Center mouse on current display | Unbound             |

Their behavior is similar to KDE Plasma's built-in shortcuts (by default, Super+F5 and Super+F6).

_Center mouse on current window_ falls back to _Center mouse on current display_ when no window is focused.

## Use Case

Sometimes, especially if you have a multi-monitor setup and/or do not use an extension like [Mouse Follows Focus](https://extensions.gnome.org/extension/7656/mouse-follows-focus/), the mouse pointer finds itself inconveniently far from the window you have focused, or perhaps you lose track of it. With Center Mouse Shortcut, you can quickly center the mouse pointer on the active window or display.
